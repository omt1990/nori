# NORI 画面仕様 v1（2026-10-13）

型名は design スキル `references/ui-vocabulary.md` の番号。挙動の細則は `interaction-conventions.md`。
スマホ1列（375px）前提。PC でも同じ1列を中央に置く。

## 共通

- ブランド：Tokyo On Foot。藍 `#1F3352`（文字・塗り）／生成り `#F1ECE2`（地）／金茶 `#B08A4A`（強調1色）。
  Zen Kaku Gothic New（和文）＋ Inter（数字・英字）。記号は菱形 ◇（空）◆（埋まり）
- 画面上の文字は 数値・ラベル・操作 の3種だけ。説明文は置かない
- 基盤：cursor・focus-visible リング・reduced-motion・disabled・外側クリックと Esc で閉じる（use-dismiss）・トースト
- 状態：読込中（S01）／通信エラーはトースト（S09）／部屋なし（S07：コードだけ出す）／記録失敗（終了後・圏外→トースト M17）

## 画面1：作る（`/`）

受け手×目的：これから遊ぶ人が初見で、1分以内に参加リンクを手に入れる。

| 軸 | 型 | 理由 |
|---|---|---|
| 1 レイアウト | 1列スタック（L01） | 入力4つを上から順に |
| 2 ナビ | なし | 1画面で完結 |
| 3 カード | 路線＝チップ（C12）を事業者ごとにグループ | 73本から2〜4本選ぶため、事業者で束ねる |
| 4 ボタン | 時間・チーム数＝セグメント（B12）、お題＝トグル（B13）、主操作＝全幅「部屋を作る」（B09） | 主操作1つ |
| 5 フォーム | 既定値あり（2時間・お題あり・2チーム）。駅数カウンタ「選んだ駅 N / 必要 M」 | 足りないときに数字で分かる |
| 6 状態 | 8時間は路線一覧を畳んで「全路線 647駅」だけ出す／駅不足→主操作 disabled＋カウンタが金茶 | 黙らない |
| 7 マイクロ | 押した反応（M01）・コピー完了トースト（M17） | |
| 8 スペーシング | 8/16/24。チップ内 8×12、グループ間 24 | |

作った後：参加リンク（`?room=XXXXXX`）と「コピー」「共有」→ そのまま画面2へ。

## 画面2：参加（`/?room=XXXXXX`・未参加）

受け手×目的：リンクを開いた人が、名前とチームを入れて10秒で入る。

| 軸 | 型 | 理由 |
|---|---|---|
| 1 レイアウト | 1列（L01） | |
| 3 カード | チーム＝選択カード（C03）に人数と名前を表示 | 人数を見て自分で選ぶ |
| 4 ボタン | 主操作＝全幅「参加」（B09） | |
| 5 フォーム | 名前1欄（F06）、20文字まで | |
| 6 状態 | 部屋なし（S07）／終了済みの部屋→画面4へ | |

参加後（ロビー）：チーム別の名前一覧・参加リンクの共有・「開始」（B09）。
開始は2チーム以上に1人ずついるとき有効。無効のときはボタンの文字を「相手チーム待ち」にする（状態ラベル）。

## 画面3：プレイ（`/?room=XXXXXX`・開始後）

受け手×目的：移動中の人が片手で、残り時間→札→到着→お題の順に操作できる。

| 軸 | 型 | 理由 |
|---|---|---|
| 1 レイアウト | 1列（L01）。上から 時間／札／盤／お題／相手の盤／ログ | 操作の順番 |
| 2 ナビ | なし（スクロール） | |
| 3 カード | 札＝大きな1枚（C01）、盤＝n×n グリッド（L06）、相手の盤＝小グリッド（C10）、ログ＝リスト（C09） | |
| 4 ボタン | 「アプリで引く」（B01）「トランプで引いた」（B02）→ ボトムシート（L20）で14枚から選ぶ。盤のマス＝到着（押すとシートで確認）。お題＝シートで一覧から1つ | 誤タップを1段で止める |
| 6 状態 | 残り時間は毎秒更新／終盤は相手の盤を◆模様で隠す／記録失敗はトースト／自分の記録には「取消」 | |
| 7 マイクロ | マスが埋まる時に短い塗り（reduced-motion で止める） | |
